# Harmony type assets

TeX Gyre Termes Regular, Italic, Bold and Bold Italic were supplied by the project owner. These four original OpenType files are included unchanged, with the supplied `GUST-FONT-LICENSE.txt`.

The Harmony opening wordmark uses contours exported from `texgyretermes-italic.otf` and bespoke connecting strokes. Its SVG artwork lives in `src/components/ui/harmony-serif-paths.js`. This artwork does not modify the font files.
