# Harmony type assets

Pacifico Regular was supplied by the project owner. The original `Pacifico-Regular.ttf` is included unchanged, with its SIL Open Font Licence in `Pacifico-OFL.txt`. Copyright 2011 The Pacifico Project Authors (https://github.com/Fonthausen/Pacifico).

The Harmony opening wordmark uses contours exported from that supplied TTF with native font spacing. Its SVG artwork lives in `src/components/ui/harmony-pacifico-paths.js`. This artwork does not modify the font file.

The previously supplied TeX Gyre Termes Regular, Italic, Bold and Bold Italic files remain stored unchanged with `GUST-FONT-LICENSE.txt`; they are not used by the Harmony opening.
